# 🎵 Spotify Hotkey Controller

A lightweight Windows application that allows you to control Spotify using customizable keyboard shortcuts.

## ✨ Features

- ▶️ Play / Pause Spotify
- ⏭️ Skip to the next track
- ⏮️ Go back to the previous track
- 🔊 Increase volume
- 🔉 Decrease volume
- 💾 Save custom hotkeys locally
- ⚡ No Python installation required

## 📥 Installation

1. Download the latest release.
2. Extract the files if necessary.
3. Launch the application.

## 🚀 Usage

1. Open the application.
2. Configure your preferred hotkeys.
3. Save your settings.
4. Control Spotify directly from your keyboard.

## 🛠️ Requirements

- Windows 11
- Spotify Desktop App
