Spotify Hotkey Controller

A lightweight Windows desktop application that allows you to control Spotify and other media players using customizable keyboard shortcuts.

VERSION:
2.0

FEATURES:

* Play / Pause
* Next / Previous track
* Volume control (up / down)
* Custom hotkey binding
* System tray integration
* Improved HUD design
* Fully closes on exit (no Task Manager needed)
* Stable background handling

HOW IT WORKS:
The application simulates Windows media key inputs, so it works with Spotify, YouTube, VLC, and most other media players without requiring any API or login.

SETTINGS:
Hotkeys are saved automatically in a local configuration file.

REQUIREMENTS:
- Windows 11 recommended
- Windows 10 not guaranteed

NOTE:
This tool uses system media keys and does not directly interact with the Spotify API.
